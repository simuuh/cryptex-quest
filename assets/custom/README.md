# Your own pictures

Put personal photos for the puzzles in this folder, for example `assets/custom/photo.jpg`.
Everything here except this README is ignored by git, so private pictures are never committed.

- Picture puzzle: about 1200 px on the short side, under 300 KB (JPG or WebP). It is center-cropped to a square.
- Memory cards: small square images, about 300 px and under 50 KB each.

Remember to upload this folder together with the rest of the app.
